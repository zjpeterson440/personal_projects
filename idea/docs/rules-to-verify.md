# Rules to verify against source

Everything here is currently encoded from recall. Each item needs checking
against the 6th ed rulebook or the relevant army book before the first playable
build is trusted. **Do not treat any of this as correct.**

Confidence is my own estimate of how likely the current encoding is right.

## Core charts

| Item | Current encoding | Confidence |
|---|---|---|
| To-hit (WS vs WS) | A>D → 3+; A=D → 4+; D>A and D<2A → 4+; D≥2A → 5+ | high |
| To-wound (S vs T) | `needed = 4 - (S - T)`, clamped to 2+..6+ | high in the middle |
| To-wound extremes | Where does it become impossible? Currently: needed >6 → cannot wound. Is S3 vs T6 a 6+ or a no? | **low** |
| Armour save modifier by S | S4 → −1, S5 → −2, S6 → −3, S7 → −4, S8+ → −5; S3 and below no modifier | medium |
| Rank bonus | +1 per full rank behind the first, needs 5+ models in the rank, max +3 | medium |
| Outnumber bonus | +1 | medium |
| Standard / flank / rear bonuses | +1 standard, +1 flank, +2 rear | **low** — flank/rear values need checking |
